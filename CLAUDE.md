# Kealee Platform — agent instructions

The platform rules live in **[KEALEE.md](./KEALEE.md)**. This file exists only
so they keep loading automatically: Claude Code reads a file named `CLAUDE.md`
by name, so renaming the instructions to `KEALEE.md` would have silently
stopped the frozen `v30` DB keys, the PGAtlas precedence and address rules, and
the execution pipeline from reaching any Claude-based agent.
