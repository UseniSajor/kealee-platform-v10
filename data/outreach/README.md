# Direct mail export — parcel owner outreach

Generated by `pnpm run export:direct-mail` or `node scripts/export-direct-mail-queue.mjs`.

Each row is a **pending** `direct_mail` queue item with a unique QR landing URL:

- Owner scans QR → `https://kealee.com/outreach/p/{token}`
- Owner submits email → intake created → lead-scoring + intelligence nurture

Send `direct-mail-queue.csv` to your print vendor (Lob, PostGrid, local mail house).

After printing, mark rows processed in Supabase:

```sql
UPDATE parcel_outreach_queue
SET status = 'processed', sent_at = now()
WHERE channel = 'direct_mail' AND status = 'pending';
```
