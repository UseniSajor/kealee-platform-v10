# Professional Review Workflow

Marketplace assignments remain canonical for scope, fees and license verification. The engineering package produces a source manifest, DXF, vector PDF, calculations, compliance results and uncertainties. A reviewer may issue traceable redlines; resolutions create a new drawing revision.

Approval requires current license verification and immutable source/sealed document hashes. A seal is never generated, copied or simulated. Release guards reject unresolved compliance blockers, unverified survey geometry, missing approval, missing sealed artifact evidence or unsealed regulated deliverables.
