# Prince George's County Residential Infill

The implemented Phase 1 rule pack screens one-to-six lots on an existing built street, land disturbance above 5,000 square feet, earth movement above 100 cubic yards, one-acre construction stormwater applicability, woodland/TCP documentation, floodplain/wetland/stream indicators, driveway/right-of-way work, survey verification and professional release.

The site plan must also resolve zoning/use, municipality, water/sewer or well/septic, existing approvals and the exact permit path. A `LIKELY_ELIGIBLE` result is not County approval. PGSCD approval/green-stamp requirements are tracked as review status; the platform never creates a green stamp.

Official sources are stored as versioned jurisdiction records. Rules fail closed when required inputs or current source verification are missing.
