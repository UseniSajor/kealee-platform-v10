## Delivery Mechanism

### 1. Owner Portal (`apps/portal-owner`)

**What:** Interactive dashboard showing all deliverables organized by category

**When:** Immediately after bot chain completes (Design → Estimate → Permit)

**Access:** Homeowner receives email with portal link + login credentials

**Features:**
- Tier-specific filtering (shows only purchased deliverables)
- Download individual items (renderings, floor plan, video, PDF)
- Share link (with expiration) for contractors/lenders
- Print-ready PDF export
- Metadata viewer (dimensions, costs, permit info)

**Example URL:**
```
https://portal-owner.kealee.com/concepts/proj_123/deliverables
```
