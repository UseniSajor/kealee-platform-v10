## ⚠️ KEY RISKS & MITIGATION

### **Risk 1: Paid Ads CAC Creep**
```
Problem: CAC rises from $120 to $180+ as competition increases
Impact: Could reduce profitability by 30-40%
Mitigation:
  - [ ] Continuous A/B testing (reduce wasted spend)
  - [ ] Organic growth (reduce reliance on ads)
  - [ ] Partnerships (lower CAC channel)
  - [ ] Have $2M contingency budget for testing new channels
```

### **Risk 2: Home Depot Deal Falls Through**
```
Problem: Partnership negotiation fails or launches poorly
Impact: Missing +160K owners, Year 1 becomes unachievable
Mitigation:
  - [ ] Start backup partnership with Lowe's + Amazon
  - [ ] If HD fails, double down on Amazon Home Services
  - [ ] Extend timeline to Year 1.5 if needed
  - [ ] Have alternative strategy (pure paid ads, influencers)
```

### **Risk 3: Contractor Churn**
```
Problem: Contractors leave because low project flow or poor matching
Impact: Homeowners can't find contractors, churn accelerates
Mitigation:
  - [ ] Enforce response time SLA (< 24 hours)
  - [ ] Remove non-responsive contractors
  - [ ] Improve contractor quality screening
  - [ ] Pay contractors faster (48-hour payout, not 14-day)
  - [ ] Have backup contractor network (subcontractors)
```

### **Risk 4: Economic Recession**
```
Problem: 2027 recession reduces renovation demand
Impact: Organic growth slows, CAC rises
Mitigation:
  - [ ] Shift messaging: "Increase home value" vs luxury
  - [ ] Offer contractor network to reduce costs
  - [ ] Implement financing options (0% APR)
  - [ ] Have $3M budget reserve for promotions
```

### **Risk 5: Competitive Response**
```
Problem: Houzz/Google launch competing products
Impact: CAC rises, brand differentiation lost
Mitigation:
  - [ ] Build defensible moats:
    1. Permits + design (unique combo)
    2. Contractor network (2-sided marketplace)
    3. Regional expertise (local knowledge)
  - [ ] Emphasize speed (AI automation advantage)
  - [ ] Build brand before competitors dominate
```
