## ⚠️ RISKS & MITIGATION (ZERO-START REALITY)

### **Risk 1: Cold Start CAC is Higher Than Projected**
```
Scenario: CAC in Month 1 is $800+ instead of $400-500
Impact: Month 1-3 burn is $4.5M instead of $3.2M
Mitigation:
  - [ ] Have $5M additional budget for testing
  - [ ] Kill channels with CAC > $600 immediately
  - [ ] Accelerate partnership timeline (get early wins)
  - [ ] Focus on organic growth (content, SEO)
  - [ ] Consider launching in 1-2 focus markets only (not nationwide)
```

### **Risk 2: Partnership Deals Don't Close**
```
Scenario: Home Depot partnership takes 6 months instead of 3
Impact: Missing 130K+ users in Months 5-6
Mitigation:
  - [ ] Have backup partners (Amazon Home Services, Lowe's first)
  - [ ] Launch without partnerships (slower, but possible)
  - [ ] Extend timeline to 18 months instead of 12
  - [ ] Build organic/paid to 150K users on your own
```

### **Risk 3: Contractor Quality Issues**
```
Scenario: Automated contractor outreach brings low-quality contractors
Impact: Homeowners can't find good contractors, churn increases
Mitigation:
  - [ ] Enforce stricter qualification (manual review first 100)
  - [ ] Implement SLA: Contractor must respond within 4 hours
  - [ ] Rate/review system (rate contractors, remove bottom 10%)
  - [ ] Hybrid approach: Automation + manual vetting
```

### **Risk 4: AI Content Quality is Poor**
```
Scenario: AI-generated blog posts/ad copy underperforms
Impact: CAC higher, engagement lower
Mitigation:
  - [ ] Have 1 content strategist review/edit all AI content
  - [ ] A/B test AI content vs human-written
  - [ ] If AI underperforms, shift budget to human writers
  - [ ] AI good for: variations, quantity | Human good for: strategy, brand voice
```

### **Risk 5: Automation Tools Don't Integrate Well**
```
Scenario: HubSpot, Apollo, Zapier have integration issues
Impact: Data silos, manual work increases
Mitigation:
  - [ ] Use native integrations (HubSpot → Zapier → Apollo)
  - [ ] Have 1 person dedicated to tool stack management
  - [ ] Build fallback: Spreadsheet tracking as backup
  - [ ] Test integrations in Month 1 (don't wait until scale)
```
